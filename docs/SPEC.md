# Spec — odin-graphene

## Packages

```
graphene/   package graphene: generated by runic from graphene/rune.yml (imports glib:gobject for Type)
```

Import through the `graphene` collection: `import "graphene:<package>"`.

## Surface

`graphene` imports `glib:gobject` for `Type`, the return type of the `*_get_type` procedures.

Every public declaration of the bound headers (Graphene 1.10.8), named as runic names
them, less the `autoptr` helpers and the version-range macros, plus the fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
